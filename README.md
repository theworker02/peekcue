# peekcue

Peek validation gates for cue inputs before they hit prod.

**Site:** https://theworker02.github.io/peekcue/

## Install / run

```bash
git clone https://github.com/theworker02/peekcue.git
cd peekcue
node src/cli.js
node --test
```
